# Reversal and momentum in Indian mid-cap equities

An independent research project testing two return anomalies on NSE data
(2005–2026): weekly cross-sectional reversal and 12-month time-series momentum.

The data come from NSE's daily bhavcopy files, so delisted companies are
included. Hypotheses will be pre-registered before any backtest is run.

**Status:** work in progress. Day 1 of 14: project skeleton and tooling.
